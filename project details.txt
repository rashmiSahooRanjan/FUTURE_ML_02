## Project Name

## Project Type
End-to-End Machine Learning + Natural Language Processing (NLP) + Interactive Web Application.

## Project Objective

Build a complete, professional, production-style Machine Learning application that automatically classifies customer support tickets into appropriate categories and predicts their priority levels.

The application should help businesses, SaaS companies, IT support departments, and customer service teams reduce manual ticket sorting and identify urgent customer problems.

The application must analyze customer ticket descriptions, understand the text using NLP techniques, predict the issue category, and assign a priority level.

The project must be fully functional, not just a UI demonstration.
